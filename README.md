# FastNeelLife Frequency Wellness

Browser-first wellness app using HTML/CSS/JavaScript.

## Run
Open `index.html` directly in Chrome, Edge, Firefox, or another modern browser.
No server is required.

## What it does
- Selects a wellness target.
- Plays a simple sine-wave tone at a selected frequency.
- Includes a session timer.
- Provides eye-rest and safe listening guidance.
- Works on mobile and desktop.

## Important
The app intentionally does NOT claim that a specific frequency releases a particular chemical,
heals disease, or produces guaranteed biological effects. Those claims require scientific evidence
and clinical context.
